# CPA Session Index

One row per session. This file is the cross-session discovery source for Conversational Pair
Architecture.

**`Status` is exactly one word:** `active | paused | design-complete | handed-off | abandoned`.
Detail belongs in the living file, not in this cell.

**`Updated` is a bare `YYYY-MM-DD`** — no parenthetical.

**`Home` is repo-relative** (`sessions/`). Absolute machine-specific paths do not resolve on
another device.

**Never leave a blank line between rows** — it splits the table in two and the second half
stops being discoverable.
